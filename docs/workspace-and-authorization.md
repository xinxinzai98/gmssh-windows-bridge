# 工作区、连接历史与独立授权

适用于 0.4.0a37 及后续稳定修复候选。源码、合成联调、Windows 原生运行和实机验收分别记录；已有 Windows 安装的升级、恢复与改密已有实机记录，具体范围见文末。公开下载页仍提供旧版 Alpha 包，候选状态见[版本说明](release-0.4.0a37.md)。

## 设备工作区

每个设备使用自己的身份、桌面、终端、文件和系统工具入口。工作区支持概览、桌面、终端及桌面与终端并排显示；分屏复用已经打开的视图，不移动或重建原生 webview。

布局、比例、画质、缩放和显示器选择按设备保存在本机。重开时恢复标签和所选工作区，其他标签在点击前不会创建桌面会话。窄窗口退回单画面；保存的显示器不存在时使用当前有效屏幕。认证失败后停止自动重试，需要用户更新认证。

- 收起或返回首页保留连接；关闭工作区只关闭工作区视图。
- 关闭桌面标签会断开该桌面；原生终端在自己的标签中关闭。
- 文件任务独立于桌面和工作区，退出应用时暂停并保存恢复记录。

连接历史仅记录设备、通道、时间、结果、时长和原因。Windows 桌面依据协议生命周期记录，Windows 终端依据后台实际通道事件记录；文件依据主进程传输生命周期记录。Linux 原生窗口未暴露终端通道生命周期，因此明确记录为“已打开原生窗口”，不将其当作已认证的终端会话。

历史可按设备筛选，保留 7、30、90 或 365 天，并单独导出。不会保存终端命令、键盘、剪贴板或屏幕内容。异常退出后，以最后一次本机心跳结束旧活动记录。历史导出与设备配置备份各有独立入口。

## 创建长期独立授权

1. 在新版 Windows 托盘打开“会话与授权”。
2. 输入管理端名称，勾选允许的通道，点击“创建并复制长期授权码”。仅看画面时只勾选“查看桌面”。也可显示刚创建授权的二维码。
3. 在 Mac 原生加号 → 添加机器 → Windows 中粘贴或扫描授权码。核对设备、端口和权限后接入。文件专用授权直接进入文件中心。

独立授权使用 `GMSSH-AUTH2.`，没有定时失效机制，可由 Windows 端单独更新或撤销。会话因异常断网且长期没有请求时会清理，但授权凭据本身不会因此过期。正常桌面和终端保持短轮询。

同一授权码复制到多台管理端时属于同一授权，撤销后一起失效。需要分别管理时，分别创建并命名授权。

管理端不会取得 Windows 账号或桌面密码。独立凭据保存在原生机器仓库；公开连接目录、工作区和传输日志不写入它。普通设备配置备份不含凭据，口令加密的完整备份可以携带该授权，用于迁移。

## 权限与断开范围

| 权限 | Windows 服务端的约束 |
|---|---|
| 查看桌面 | 创建桌面通道前检查；实际桌面认证由服务端完成 |
| 键盘与鼠标 | 拒绝相应协议消息，并固定引擎登录选项 |
| 文本剪贴板 | 按权限过滤双向剪贴板通道；不开放引擎的剪贴板文件通道 |
| 文件读写 | 每个文件及文件句柄请求检查授权与会话归属 |
| 终端 | 会话、命令、ConPTY 输入和缩放均检查权限 |
| 电源 | 只允许固定的重启、关机和取消命令，并检查电源权限 |

所有已授权管理端可以读取设备监控和固定的只读工具。这些通道权限不是 Windows 系统沙箱：允许键鼠、文件写入或终端后，持有人可能通过 Windows 本身执行其他操作。

Windows 会话列表列出独立授权通道及开始时间、状态和来源。断开单个会话不停止 SSH、桌面引擎或其他管理端；撤销授权会结束它的通道并拒绝旧凭据。会话空闲 30 分钟后自动释放，不会因管理端异常退出而永久占用。

原有共享密码、手动 SSH 和 `GMSSH-CONNECT1.` 保留。它们没有自动迁移成独立授权，也不在独立授权会话列表中。撤销新授权不能撤销别人已经掌握的旧共享密码；需按原共享密码流程处理。

## 实现与验证边界

新授权沿用受管理安装的 HTTPS 22257、来源限制及启动任务。发送凭据前校验证书、设备身份及完整证书内容，支持提供的 IPv4/IPv6 地址；不管理路由、DDNS 或地址变化。

Windows 使用内置的 [ConPTY API](https://learn.microsoft.com/en-us/windows/console/creating-a-pseudoconsole-session) 保持交互式终端，并以作业对象回收该终端创建的进程。后台使用受管理账号启动终端，不将它替换成 SYSTEM 交互式 shell。

本地联调使用真实 Go HTTPS、Python、SSH 和主进程传输代码，Windows 进程、CIM 和桌面端点由合成实现提供。实机检查已覆盖已有安装的升级、服务与托盘恢复、不同密码重连、临时 Mac 客户端完整退出重开后的监控和桌面自动连接，以及独立文件授权降级、撤销、原会话拒绝和并发隔离。原生 ConPTY、未逐项执行的其他通道权限仍按各自边界补验，不能由安装自检或文件通道的通过结果代替。详细版本与结果见[验证记录](validation.md)，日常 Mac 应用未替换。
