# 0.4.0a40 Mac 更新兼容修复 Alpha

本版提供新的 Mac 安装／更新 ZIP、wheel、自有源码 ZIP 和 SHA-256 清单，包含 a39 之后的更新器兼容与测试修复。a39 标签和下载文件保持原样。本轮没有新的 Windows 安装器，不公开完整原版 GMSSH App、原版运行组件或设备配置。

离线更新入口支持现有 `0.4.0a38` 的标准增强端及已知 `local.gmssh.windows.launcher.preview.unlock225` 预览版，精确匹配标识，不放行其他预览后缀。更新保留应用标识、helper 名称、配置、独立 Python 路径、包内原版资源及主程序 UUID。签名、ASAR、运行环境版本和退出状态检查继续生效；失败恢复与显式回退沿用原有备份流程。当前不支持从已安装 a39 直接更新到 a40。

默认 macOS 临时目录下的回退夹具已规范化路径。标准与已知预览标识各有 14 项更新器测试；这些测试中的签名和进程调用仍是模拟。Vite 开发依赖更新到 7.3.7，前端重建内容与此前 a39 一致；不据开发依赖告警推断已安装客户端存在相同暴露。

本地检查、原生升级验收和 GitHub CI 分开记录。实际完成的原生升级、回退与界面范围以本版 Release 的验证记录为准；不能将源码回归或平台跳过视为真实设备验收。账户计费锁定仍可能阻止 GitHub Actions 启动。

先从菜单正常退出客户端，再完整解压 Mac ZIP，运行 `Update GMSSH.command`。`--check` 只检查前置条件；更新器不自动启动或连接设备。回退命令和支持范围见[安装与接入](getting-started.md)及[更新器兼容说明](macos-updater-compatibility.md)。
