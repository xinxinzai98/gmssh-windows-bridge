# 安装与接入

公开 Release 与源码候选的版本分别标在首页。当前源码候选为 **0.4.0a35**；下载时核对文件名、版本和同一目录的 `SHA256SUMS`，不要把旧发布包当作当前候选。本轮支持范围是 **Apple Silicon Mac 控制端、Windows 11 x64 被控端、两端内置本地磁盘**。不要求 Tailscale，局域网可直连即可。

## Windows 安装或升级

1. 运行 `GMSSH-Windows-Setup-版本号.exe`，完成正常 Windows 管理员提示。
2. 安装器先检查电脑现状，再显示相应流程：
   - **新安装**：设置一次 GMSSH 连接密码，创建专用本地管理员账号 `gmssh`，安装后台桌面引擎、托盘和接入任务。原 Windows 用户密码与 PIN 保留。
   - **保留现有服务**：适用于兼容的既有 OpenSSH/RustDesk 和管理员账号。分别验证已有 Windows 账号密码与桌面固定密码，保留原服务、账号、密码和 SSH 主机密钥。条件不符时停止，不自动提升账号权限。见[保留接入](preserve-existing.md)。
   - **升级 / 修复**：先备份 GMSSH 自身文件，再更新程序与任务，保留设备身份、连接配置和独立授权。不要预先删除安装目录或账号。
   - **重新安装**：识别此前正式卸载留下的记录，验证备份后恢复配置，再应用当前版本。见[卸载与重装](uninstall.md)。
3. 按安装结果提示打开托盘面板，核对电脑名、当前地址、SSH/桌面及接入服务状态。取消、失败与服务未就绪会分别提示；失败时保留备份，不以文件复制完成代替安装成功。

SSH 和桌面引擎包含在完整安装包中，无需从 Windows 可选功能下载 OpenSSH。仅缺少所需 VC++ 运行库时，从微软官方获取并核对固定摘要与签名；下载失败可先从[微软官方页面](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)安装 x64 运行库，再重跑安装包。

账号密码、桌面连接密码和 Windows 解锁密码用途不同；Windows PIN 不作为 SSH 密码。保留模式允许原 Windows 和桌面密码不同，不会为了统一连接擅自修改它们。

## Mac 准备

1. 安装并打开官方 **GMSSH 2.0.4 Apple Silicon**，确认首页可使用后正常退出。其他基座版本不会自动覆盖或降级。[官方安装文件](https://gmb-prod-gw.oss-accelerate.aliyuncs.com/client/mac/arm64/2.0.4/GMSSH-mac-2.0.4-arm64-pro.dmg)。
2. 解压同版本 `GMSSH-Mac-Setup-版本号.zip`，运行 `Install GMSSH.command`，生成 `~/Applications/GMSSH 局域网增强端.app`。
3. 正常退出其他 GMSSH 实例，打开增强端，按 macOS 提示允许局域网访问。

Mac 包包含本项目组件与独立运行环境安装器，使用本机已有的官方 GMSSH；不附带发布者的设备列表、密码、钥匙串或登录状态。许可与打包边界见[发布说明](releasing.md)。

## 添加设备：授权码、二维码或手动填写

统一入口为首页左侧 **加号 → 添加机器 → Windows**，无需另外寻找 Windows 接入按钮。

- **独立授权（推荐）**：Windows 托盘进入会话与授权管理，选择允许的监控、桌面、键鼠、文件、终端或电源能力，创建长期授权，再复制授权码或显示二维码。在 Mac 粘贴或扫描后核对电脑与身份并添加。二维码内是同一段配置，可用其他扫码工具读取后粘贴。撤销和降级由服务端逐请求执行，不需要交出 Windows 登录密码。见[工作区与授权](workspace-and-authorization.md)。
- **原有连接码**：受管理账号可复制长期连接码，一键填写 SSH 连接；不会把明文密码放进码内，但持有码的人可以接入，应按密码保管。改连接密码后旧码失效；只重置连接码不撤销已保存的 SSH 密码，撤销这类旧连接需改密码。
- **连接文件 / 手动填写**：保留导入 `GMSSH-connection.json` 和手动输入地址、SSH 端口、账号及密码的方式。首次连接核对 Windows 导出的 SSH 指纹；不要将 PIN 当作账号密码。

同一身份再次导入更新原卡片，不创建重复设备。桌面认证成功后才按勾选项保存到 Mac 钥匙串；保存表单本身不代表已经连通。

一键接入使用 TCP 22257、设备独立证书与 SYSTEM 开机任务。凭据通过 Windows DPAPI 保存在受限目录；标准安装只允许同一子网接入。授权码、二维码和连接文件不要发布到仓库、Issue 或公开截图。

## 地址与 IPv6

只使用用户提供的地址，不扫描其他电脑、不管理动态或静态地址。自动顺序为本地 IPv6、本地 IPv4、其他 IPv6、其他 IPv4。手动输入 IPv6 时地址与端口分开；合写时用 `[2001:db8::42]:2222`。链路本地地址需附正确作用域。

跨网段 IPv6 需要用户明确批准的来源和对应防火墙规则，不能据同一局域网通过推断公网可达。Windows 面板可导出全部可用 IPv6，并按用户操作启用 Ping；地址显示不替代身份核验。

## 日常使用与维护

- **监控与工作区**：同一卡片显示资源、连接状态与延迟；原蓝色桌面图标打开顶部标签。工作区串联概览、桌面、终端、文件、历史及只读系统工具。Linux 与 Windows 保留各自系统图标和连接方式。
- **文件中心**：独立于桌面画面，流式上传/下载，支持暂停、断线续传和管理端重开恢复。任务保存在主进程；恢复前重新确认源文件或保存位置，再校验主机与内容。同名目标不覆盖。主进程路径单文件上限 1 TiB，旧浏览器侧栏仍为 512 MiB。当前验收只针对内置本地磁盘。见[文件中心](file-center.md)。
- **配置转移**：导出时勾选指定设备；普通配置不带秘密，完整备份使用用户口令加密。导入前预览、勾选并处理重复身份，详见[配置备份](../README.md)。
- **改密**：受管理安装在托盘修改连接密码后，Mac 更新原设备凭据并重连；保留模式使用“更新接入凭据”验证并保存原账号/桌面凭据，不修改原密码。独立授权可分别撤销。
- **重启恢复**：SSH 与桌面服务在开机后恢复，用户登录后启动托盘。可选 Windows 自动解锁默认关闭，需另外启用并将系统密码保存在本机钥匙串；不使用 PIN，不接受 UAC 提权。见[可选系统解锁](windows-unlock.md)。
- **卸载恢复**：从 Windows 设置卸载，先核对移除与保留清单，确认后备份移除自身组件；运行完整安装包恢复。用户文件及原 SSH/RustDesk 保留。

## AI：CLI 与 MCP

安装可选 AI 依赖后，按 [AI 接入](ai-access.md)启用指定设备。CLI/MCP 共用 25 个工具，使用独立授权和本机允许列表；不会自动导入所有 GMSSH 设备或账号密码。

建议先观察窗口、查找控件，再执行操作并重新观察确认。0.4.0a35 增加窗口根节点的 `focus` 操作，可请求恢复最小化窗口并激活；旧服务端会提示升级。只有服务端允许键鼠且已确认前台窗口时才能输入。锁屏、UAC、安全桌面、密码框及焦点拒绝均停止，不盲目重放输入或命令。

已实机完成的升级、卸载重装、改密重连、重启恢复、CLI/MCP 中文输入保存、权限隔离等范围见[验证记录](validation.md)。纯净系统完整首装和未逐项执行的工具保持各自未验边界；平台跳过不算通过。旧版逐次变化保留在 [CHANGELOG](../CHANGELOG.md)，本指南只描述当前流程。
