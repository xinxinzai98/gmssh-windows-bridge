# 安装与接入

公开下载目前为 0.4.0a8 Alpha 预览版；下文另标出尚未发布的候选流程。Windows 电脑安装被控端；Mac 安装增强控制端。两台电脑需要能在同一局域网互访，不要求安装 Tailscale。

## Windows 电脑

1. 从本项目的 GitHub Release 下载 `GMSSH-Windows-Setup-版本号.exe`，运行并完成正常管理员提示。
2. 阅读安装说明，亲自设置 GMSSH 连接密码。安装会新建专用本地管理员账号 `gmssh`，安装后台桌面引擎和托盘，并允许同一子网访问 SSH 22 端口；原 Windows 账号密码保留。若已有冲突账号、SSH 或桌面服务，会停止并提示检查。
3. 将桌面生成的 `GMSSH-connection.json` 交给控制端使用者。该文件不含连接密码，但包含设备地址和身份，只交给需要连接这台电脑的人，不上传到公开仓库；通过可信渠道单独告知连接密码。

SSH 和桌面引擎包含在安装包中，无需从 Windows 可选功能下载 OpenSSH。仅缺少所需 VC++ 运行库时，安装器才联网从微软官方获取，核对固定 SHA-256 与签名后安装；下载失败可先从[微软官方页面](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)安装 x64 运行库后重试。

托盘中可查看状态、复制连接信息和修改连接密码。系统保护目录及其他账号的加密文件仍受 Windows 权限限制。

## Mac 控制端

1. 先安装原版 GMSSH **2.0.4** 到 `/Applications`。安装器会复用可用的 Python 3.12–3.14；没有时，从固定的 [python-build-standalone 官方发布](https://github.com/astral-sh/python-build-standalone/releases/tag/20261013)获取独立 Python 3.12，并校验 SHA-256。无需手工安装 Python，也不修改系统 Python；首次准备运行环境需要访问 GitHub 和 PyPI。
2. 下载并完整解压 `GMSSH-Mac-Setup-版本号.zip`，双击 `Install GMSSH.command`。它只安装本项目的独立运行环境，再使用本机已有的原版 GMSSH 生成 `~/Applications/GMSSH 局域网增强端.app`。
3. 正常退出其他 GMSSH 实例，打开新入口，并按 macOS 提示允许局域网访问。首页打开 Windows 添加入口（0.4.0a12 起为左侧加号 →“添加机器”→“Windows”；早期包为“接入 Windows”），导入连接文件，核对电脑名、地址与 Windows 端的 SSH 指纹，再输入连接密码。

原版 2.0.4 官方下载：[Apple Silicon](https://gmb-prod-gw.oss-accelerate.aliyuncs.com/client/mac/arm64/2.0.4/GMSSH-mac-2.0.4-arm64-pro.dmg)、[Intel](https://gmb-prod-gw.oss-accelerate.aliyuncs.com/client/mac/x64/2.0.4/GMSSH-mac-2.0.4-x64-pro.dmg)。2026-10-15 已核对两种架构的官方更新清单和下载响应；Intel 增强端仍待实机验收。已有其他版本时先保留，安装器会停下提示，不自动覆盖或降级。

首次接入会建立监控卡片与桌面入口。新版连接文件声明共用密码时，桌面首次认证复用本次输入；勾选记住后，通过认证才保存到这台 Mac 的钥匙串。同一身份重复导入会打开已有设备。

Mac 包不包含原版 GMSSH 的完整程序，不携带发布者的设备列表、钥匙串、登录状态或预览应用。原版依赖与许可边界见[发布说明](releasing.md)。

## 0.4.0a9 候选的升级与改密

此候选已在 Windows 11 测试环境完成已有安装升级、重启恢复、改密后重连及 Mac 应用重开后的自动连接验收，尚未作为公开稳定功能发布。

- **Mac 首次准备：** 先打开官方 GMSSH 2.0.4，确认设备首页可以使用，再退出并运行增强端安装器。候选安装器会检查原版的本地服务资源，并注册生成的应用。
- **Windows 已有安装：** 重跑候选安装器，选择“升级 / 修复”。程序先备份自身文件，再更新程序和登录自启任务，保留已有账号、密码、SSH 主机密钥和桌面引擎。不要先手动删除账号或安装目录。
- **重启后：** SSH 与桌面服务自动启动；原用户登录后恢复托盘。可从托盘查看状态、自检或重新导出当前连接地址。
- **修改密码：** 在 Windows 托盘选择“修改连接密码”，亲自输入并确认新密码。在 Mac 再次导入同一电脑的连接文件，勾选“更新此设备的连接密码”，输入新密码后点击“更新密码并重连”。原卡片和标签入口保留；勾选记住时，桌面认证通过后再更新本机钥匙串。

## 0.4.0a10 候选的长效连接码

此候选已在已有受管理的 Windows 11 测试机完成升级、首次启用、复制码和 Mac 粘贴重连。全新安装、连接码服务的开机恢复及改密 / 重置后的两端流程仍待实机验收。

1. Windows 新装时设置一次 GMSSH 连接密码。已有受管理安装选择“升级 / 修复”，保留原密码；首次复制连接码时，亲自验证一次现有密码以启用。
2. 在 Windows 托盘面板点击“复制连接码”。在 Mac 首页点击左侧加号 →“添加机器”→“Windows”→“粘贴连接码”，核对电脑和地址后点击“接入并打开桌面”。不需要再次填写密码。0.4.0a12 以前的控制端入口名称为“接入 Windows”。
3. 同一电脑再次粘贴会更新原卡片并重连；“选择连接文件”和原有手动添加仍保留。已有独立 SSH / RustDesk 的电脑继续使用手动方式，安装器不会自动接管或重设它们。

连接码可重复使用，不设短期倒计时；不包含明文连接密码，但持有码的人可以接入，应按密码保管。不要发布到仓库、Issue 或公开截图。改连接密码后，旧码失效；托盘右键“重置连接码”也可仅让旧码无法再添加。已经保存密码的控制端连接不因重置码而失效；要撤销它们，请修改连接密码。

一键接入使用局域网 HTTPS TCP 22257、开机任务 `GMSSH Windows Connect` 和每台设备独立的证书。防火墙仅允许同一子网访问。Windows 连接密码和证书私钥以 DPAPI 密文保存在本机受限目录，Mac 先核对 SSH 主机身份，再验证连接码内的设备证书；不把固定密码放入连接码、URL 或本项目设备目录。原有 GMSSH 凭据保存与可选本机钥匙串仍用于以后重连。

## 0.4.0a11 候选的 IPv6 接入

首页左侧加号 →“添加机器”→“Windows”保留连接码、连接文件和“手动填写”三种方式。可填写提供的 IPv6 地址（如 `2001:db8::42`），SSH 端口单独填写；带端口时使用 `[2001:db8::42]:2222`。手动接入先读取主机指纹，与 Windows 端核对后再输入密码。

已有设备右键选择“编辑连接地址”，填写新的 IPv4 / IPv6 地址并输入当前连接密码，即可更新原卡片。连接码预览也允许填写新地址；核验仍使用码内同一台电脑的 SSH 公钥和设备证书。更换地址时保留卡片、标签入口和本机端口，失败则恢复原配置。完整地址可悬浮查看并点击复制。

地址由使用者提供，程序直接连接，不管理静态 / 动态地址、DDNS、路由或打洞。目标网络需要已允许相应访问；默认安装器仍只允许同一子网。IPv6 连接码的额外来源授权及验收边界见 [IPv6 说明](ipv6.md)。此候选已通过本机 IPv6 协议检查，公网 Windows 实机验收尚未完成。

## 0.4.0a12 候选的统一添加入口

首页不再单独提供“接入 Windows”按钮。点击原来的加号，在“添加机器”中选择 Linux 或 Windows。Linux 沿用原生表单、测试连接、密码 / 密钥和高级设置；Windows 在同一个窗口内提供连接码、连接文件和 IPv4 / IPv6 手动填写。切换回 Linux 保留 Linux 草稿并清除 Windows 临时密码，关闭和取消也会清除临时凭据。正在核对或接入时，请等待当前操作完成。

系统选择位于标题栏右侧。Windows 接入方式等宽排列；手动填写时，地址和端口放在同一行，先点击底部“核对主机身份”，核对后再填写密码并接入。连接码会自动填写连接信息，原有设备沿用同一张卡片。

## 遇到问题

- 浏览器或系统的安全提示由使用者亲自处理；遇到不理解的提示先停下核对。
- 无法连接时先检查局域网地址、Windows 托盘自检，以及 Mac 的局域网授权。Windows PIN 不是 GMSSH 连接密码。
- 已有同名 GMSSH 账号或 SSH 服务时，先确认用途；安装器不会自动覆盖它们。0.4.0a8 的已有安装重跑仅保留密码并执行自检；0.4.0a9 候选支持前述“升级 / 修复”流程。
- 反馈可提供版本、系统版本与错误文字。不要公开上传连接密码、钥匙串、GMSSH 数据库、私钥、完整日志或含真实设备的截图。

目前已验证 Apple Silicon Mac 与 Windows 11 测试环境，以及 Linux 首页的原生摘要详情。0.4.0a9 候选的已有安装升级、Windows 重启恢复、改密后重连和 Mac 应用重开已通过；全新电脑上 OpenSSH MSI 首装、硬件唤醒、整台 Mac 重启及 Intel Mac 仍未完成实机验收。请先用于可接管的测试电脑。
