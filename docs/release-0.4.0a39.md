# 0.4.0a39 Mac 控制端 Alpha

本版针对 Mac 增强端，发行状态及附件以 [Releases](https://github.com/xinxinzai98/gmssh-windows-bridge/releases) 为准。提供自有源码、wheel 和 Mac 安装／更新 ZIP；本轮没有新的 Windows 安装器。包内不包含完整 GMSSH App、原版运行组件、设备资料或密码。

远程桌面的设备工作区导航与桌面控制合并为一行，设备和文字连接状态保留。桌面／终端、缩放、当前设备文件和放大可直接使用；画质、快捷键、剪贴板、电源、分屏、工具和记录进入菜单。单设备不显示无效下拉，显示器选择仅在多屏出现，窄窗口继续显示状态和文件入口。

已有 0.4.0a38 增强端可使用 ZIP 中的 `Update GMSSH.command`：先正常退出客户端，再运行更新命令。更新器复用现有独立运行环境和包内原版资源，不依赖另一份原版 App；核对 wheel、ASAR 与签名，保留配置和主程序 UUID。失败自动恢复旧组件，另提供显式回退命令。首次安装仍使用 `Install GMSSH.command`，需已有受支持的 GMSSH 2.0.4 基座和初始化的本地服务。

本版沿用此前已完成的功能与连接修复，历史原生证据见 [0.4.0a38](release-0.4.0a38.md)。单行工具栏有 62 项合成浏览器检查；新增更新器覆盖文件校验、签名失败恢复、配置与 UUID 保留、互斥、损坏包拒绝和中断后回退。新更新器的 Mac 原生安装未在云端实测，不将模拟签名调用或平台跳过记为实机通过。

Mac ZIP 内提供校验清单；Release 根目录的 `SHA256SUMS` 对应 ZIP、wheel、源码和说明。完整 App 属于用户本机安装结果，不能作为通用公开附件。操作步骤和回退方式见[安装与接入](getting-started.md)。
