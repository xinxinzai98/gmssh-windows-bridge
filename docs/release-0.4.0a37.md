# 0.4.0a37 Alpha 候选说明

状态：本地候选，尚未发布。公开 Release 附件仍为 0.4.0a8；本文件描述 0.4.0a37，不将旧包列为新版下载。安装步骤见[安装与接入](getting-started.md)，原始验证结果见[验证记录](validation.md)。

## 范围与组成

支持范围为 Apple Silicon Mac 管理端、Windows 11 x64 服务端及内置本地磁盘。面向局域网，使用用户提供的 IPv4/IPv6 地址；不内置 Tailscale，也不代管地址分配、路由或 DDNS。

- Windows：一个 GMSSH 安装入口、后台接入与托盘，内含固定的离线 OpenSSH 和未修改的桌面引擎。缺少 VC++ 时从微软官方下载并校验；兼容的既有 SSH/RustDesk 使用保留接入。
- Mac：提供本项目安装脚本与 wheel，在用户本机的官方 GMSSH 2.0.4 基座上生成增强入口。首次准备运行环境和依赖需要联网，不附带发布者的原版程序、完整 `.app`、设备列表或凭据。
- 源码与校验：同版本源码 ZIP、wheel 和 SHA256SUMS。公开导出只使用允许的项目源码，组件与原始固定摘要对应。

Intel Mac、外接盘/NAS、音频、录屏和远程打印不纳入本轮支持与验收。

## 已有功能与本轮变化

监控、设备列表与顶部桌面标签、终端、Windows/Linux 独立文件中心、配置导入导出、长期授权码/二维码、工作区与历史、系统只读工具和 CLI/MCP 已有实现。

0.4.0a36 为文件任务增加有界启动等待、分阶段失败原因及脱敏“复制诊断”；0.4.0a37 对 HTTPS 握手、请求和空闲复用使用明确预算，传递可解释的桌面错误，并修复超时后共享认证状态导致重连无法发起的问题。

候选整理时还修复 IPv6 设置保存后核验失败的记录回退：向 File.Replace 传入实际空备份路径，避免 PowerShell 将其绑定为空字符串而使回退失败。临时文件回归核对原记录字节、模拟的两条自有防火墙规则与无关规则；此项未部署到现有设备，不代表完成新的 Windows 防火墙实机验收。

对于已保存认证的明确传输中断，管理端按 2/4/8 秒间隔、最多尝试三次新连接。每次仍核验证书、当前授权与权限；认证失败、身份变化、权限拒绝、主动断开或页面关闭会停止。恢复不重放键鼠、命令或文件写入，Windows 自动解锁仍按原有的单次提交边界执行。

## 已知限制与发布条件

Wi-Fi 的偶发长停顿仍未定位。后续只读设备对照和临时桥接绑定测试没有复现原故障，不能据健康窗口认定已根治或归因于某个网卡组件。自动恢复改善中断后的行为，不保证连接始终无中断。

Mac 安装脚本当前用于首装；发现已有同名增强应用时停止并保留原环境，不无提示覆盖。日常应用、私有配置与钥匙串不作为通用安装包的一部分。完整原版 GMSSH 的再分发与本项目代码许可分别处理，见[发布说明](releasing.md)。

本项目封装的 Windows 安装器未作发布者代码签名，Mac 本机生成的增强应用使用 ad-hoc 签名，未经过 Apple 公证；包内第三方组件的原始签名与本项目安装器的发布者身份分别核对。下载后先核对来源与 SHA256SUMS，系统安全提示由使用者在正常界面处理。

本地构建、版本/组件对应与净化检查，以及 GitHub CI 分开记录。源码推送与安装附件发布分开，本候选没有公开 Release；远端 CI 以对应提交的实际运行结果为准。正式附件发布前还需核对实际 CI 和发布清单；未验功能继续标明，不以平台跳过或模拟结果替代实测。
