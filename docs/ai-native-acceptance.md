# AI 接入的 Windows 原生验收

此清单用于独立的 Windows 测试电脑，可以是虚拟机或闲置实体电脑。虚拟机用于隔离安装、重启和权限测试，正式用户直接安装服务端，不需要虚拟机。逐项记录实际结果；部分原生回归通过不能代替整套验收。

开始前记录电脑名、系统版本、候选包 SHA-256、当前安装版本和恢复方式；确认允许该设备安装、重启及修改本程序的独立授权。使用独立接管通道，保留程序升级备份。密码由使用者在正常窗口输入，不写进记录、命令参数或聊天。已有安装优先验证升级，空白环境另验首装，二者不能相互替代。

## 安装与恢复

1. 安装或备份升级当前候选，核对安装自检、账号和 SSH 主机身份保留。启动托盘、查看监控、桌面、终端及文件中心；记录实际结果，不只记进程启动。0.4.0a34 起可使用正式卸载与保留重装，在同一台已授权电脑重复维护流程，见[卸载说明](uninstall.md)。
2. 正常重启，分别检查登录前服务恢复、登录后托盘/交互工作者、客户端重开后的原设备连接。改连接密码后验证旧密码拒绝、新密码重连；改密需要独立授权，不能在无人确认时自行设置。
3. 记录 Windows PowerShell 5.1 下原生 UI、脚本与 helper 的运行结果；macOS 解析和 Windows PE 交叉编译不能代替这一步。

## 只读、撤销与隔离

1. 从托盘创建一个“AI 只读预设”授权，核对只有查看和文件读取；另建不同授权作对照。只读接入检查应显示 `serverFileAccess: read-only`，旧读写授权仍显示 `read-write`。
2. 在临时目录准备已知内容和 SHA-256。验证文件浏览、下载、CLI/MCP 搜索/读取/预览可以使用，预览不创建备份；上传、新建、替换、删除、重命名都拒绝。用受控原始文件 API 重复写入请求，确认限制来自服务端；核对目录和原文件哈希不变。
3. 将读写授权降为只读，旧文件会话应失效；重连只能读取。撤销后原授权认证失败，对照授权和普通 SSH 不受影响。单会话断开只影响选中会话。
4. 在受控慢 I/O/长任务时撤销，记录管理操作延迟与“正在结束”状态。新/排队请求应拒绝，命令不假报成功，客户端不自动重放。核对任务状态和已发生的影响；不能把撤销当成事务回滚。

## AI 桌面与中文保存

先用高分辨率桌面检查截图：返回图片及尺寸必须不超过 1600×1000，`desktopBounds` 仍保留原始桌面范围。`tests/windows-ai-screenshot-checks.ps1` 只执行源码中的缩放表达式及原生按键参数转换，不访问桌面或发送输入；完整截图与按键仍需实机验证。

1. 测试用户先正常打开记事本和空白临时文本。通过 `desktop_observe`、`desktop_find` 获取实际窗口/控件，再以 `desktop_act` 输入一段中文、数字和换行，重新观察核对内容。
2. 使用实际控件或已支持的有限按键保存到已确认的临时路径，重新读取内容和哈希，再关闭/重开文本核对。没有应用启动或保存的可靠控件时记为受限，不能用合成结果代替完成；本版本没有通用应用启动接口。
3. 分别验证托盘暂停输入、解暂停、锁屏、解锁、过期控件、同名控件和目标应用退出。锁屏应明确报告，迟到动作不得输入到另一个窗口；UAC/安全桌面不自动操作。
4. 从真实 MCP 客户端完成一次发现工具、只读查询、桌面观察及明确授权的输入；保留去除输出和凭据的结果摘要。MCP 配置仅由使用者明确安装，不自动改现有客户端。

验收记录区分通过、失败、受限和未执行，并标明来源是原生 Windows、回环协议还是合成界面。失败时先记录原状态及回退结果，不反复执行可能产生修改的操作。
